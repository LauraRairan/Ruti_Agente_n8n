# ruti-agente-n8n
Agente de IA en Telegram creado con n8n, Gemini y Supabase (RAG). Responde preguntas de una empresa ficticia, agenda pruebas de manejo y envía confirmaciones por Gmail. / AI agent on Telegram built with n8n, Gemini and Supabase (RAG). Answers questions about a fictional company, books test rides and sends Gmail confirmations.
